# PlotTrial 操作手册

知华科技（上海如静知华信息科技有限公司） · <https://www.zhuatech.cn/> · 商业咨询微信 zhuatech / zhuatech2。

## 管理员准备

使用本机初始化配置中的口令登录 admin。创建部门和人员，分配“试验设计”“独立复核”“田间观测”岗位。设计人与复核人分开；复核人不得参与该方案编辑，也不能被指派为该试验观测员。启停和权限变化在下一次请求生效。菜单和权限代码固定，管理员可以改说明、导航顺序、启停及角色授权。companyName 修改工作台标题；maxRecords 限制全库田块与试验分别 100—1000 条；timezone 固定 Asia/Shanghai。

## 设计人员

在“田块目录”建立真实田块。新建试验，选择田块与复核人，填写作物、目标、4—16 个区组及正小区面积。方案页分别添加处理与指标：启用处理 2—12 项，恰好一个对照；指标必须是数值型、有单位和允许范围，至少一项必录。每试验最多保存 12 项处理和 20 项指标（包含不启用条目）。

提交后交由指定复核人批准，或退回修订。审批完成方案冻结。点击“生成随机布局”只执行一次，布局种子保存于证据页；不能手动调换或重抽。随机布局表示区组内的位置次序，不含地图坐标、导航或实体标牌打印。

逐小区指派观测员，等待本人收悉。全部完成后登记真实开始日期。启用后不能更换观测员；停用账号会阻止该账号继续操作，应在开始前确认岗位安排。

## 观测员

登录后仅看到本人指派小区。确认收悉；试验开始后逐小区登记真实种植日期，不能早于开始日或晚于今天。录入指标时，填写**数值**并留空缺测原因，或留空数值并填写**明确缺测原因**。零是合法测量值，不等同缺测。观测日期不得早于该小区种植日期或晚于今天；数字最多四位小数，并符合方案范围。负数只在方案允许范围包含负数时有效。

观测保存为草稿，可编辑、提交、撤回、退回后修改或取消。独立复核后不能原地编辑；选择“追加修订”，填写原因并指向当前核实记录。同一小区指标只能有一个待处理记录；修订核实前旧核实版本仍参与汇总。被取消的修订不替代旧事实。

小区异常需排除时提交事实原因，由复核人决定接受或拒绝。接受后该小区不再计入有效数值，但历史记录保留；本版不提供撤销已接受排除。仍有待处理观测时须复核或取消，不能靠排除跳过待处理状态。

## 独立复核与结束

指定复核人审核方案、核实观测、决定排除，不能核实本人填写的观测。方案编辑人与关单复核人必须分开。设计人员正常结束前，每个未排除小区已种植，所有必录指标的当前记录已核实（数值或明确缺测均可），无待处理观测、无待排除申请，并至少留一个未排除小区。

结束后复核人可退回继续观测，或复核关单。中止允许未完成必录数据，但仍必须清理待处理观测和排除；关单时保留中止结局。关闭后的数据摘要与原始证据固定，不能再录入。试验开始前可以取消，不自动删除任何记录。

## 数据阅读与导出

统计按处理及指标显示 N、缺测、排除、未录、均值和极值。N 只计当前核实且未排除的数值，缺测不填零。均值显示四位小数，无有效数值时为空。小区排除数针对该处理指标列示。描述统计不判断显著性。

JSON 含授权范围内完整方案、修订、事件与摘要；CSV 含全部授权观测版次及 currentAccepted 标记。导出不附推广信息。证据快照用于回看事实，不是具备外部签名的防篡改认证。数据和备份应留在授权范围。

界面提供中文／英文切换；手机适配允许表格区域横向浏览。详细规则见本手册，日常页面保留必要操作。非商业源码版未经书面授权不得商用；商业授权及部署咨询使用以上官网与微信。

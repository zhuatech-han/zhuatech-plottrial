# PlotTrial 架构与数据

知华科技（上海如静知华信息科技有限公司） · <https://www.zhuatech.cn/> · 商业咨询微信 zhuatech / zhuatech2。

## 身份与事务

Nginx 提供前端与 /api 同源代理。Spring Security 会话 Cookie 认证与 CSRF；AccessService 从数据库重新检查账号、散列和角色。业务事务以总部 Department 锁统一串行化，避免同一个观测单元产生多个待处理版本。此实现用于有界的小团队记录，不宣称高并发吞吐能力。

业务命令携带 UUID requestKey 与版本。相同账号、路径与有效输入重复请求返回保存的响应；不同请求指纹冲突。岗位和范围检查先于重试读取；失败事务不消费键。响应读取保留十进制精度。状态字段、随机种子、软件事实时刻不接受客户端修改。

## 表与约束

V1：account、access_role、role_permission、department、permission、nav_menu、dictionary_entry、system_setting、audit_event。

V2：field_site、trial_plan、trial_editor、treatment、measure_definition、trial_plot、observation、command_record、business_event。

加 flyway_schema_history 共19表。外键保护关联身份；试验内处理和指标编号、小区位置、观测版次唯一；区组数、小区面积、指标范围和版本有数据库约束。Java 层执行状态与岗位规则，数据库层继续检查身份与基础一致性。

田块与试验全库各最多 maxRecords（100—1000）；观测全库最多10000条（包括草稿、取消及历史修订）；处理每方案最多12，指标最多20。分页在授权过滤后切片，size为1—100；因此不适用于不设上限的大数据平台。

## 冻结与随机布局协议

方案批准保存 planHash，处理、单位、范围不再允许改动。审批时冻结田块名称，后续目录改名不回写。布局按启用处理代码排序，以0为起点形成索引。每区组独立生成排列：从末尾 i=n-1 倒序到1，counter从0开始；SHA-256 输入为 UTF-8 `seed:block:counter`，seed为64位小写十六进制，block为1起始十进制，counter每次采样递增。读摘要首4字节为无符号32位大端整数；bound=i+1，limit=2^32−(2^32 mod bound)。draw≥limit重新取样，避免取模偏差；用draw mod bound与i交换。

算法标记 SHA256-FY32-v1。固定示例：64个字符0的种子、block=1、n=4，输出索引[3,2,1,0]。种子是公开复现资料，不是认证凭据。完整布局只创建一次；服务端 SecureRandom 生成种子。摘要为应用序列化数据的 SHA-256，不是外部公证、数字签名或不可篡改存储。布局种子与协议是跨实现复现排列的依据，摘要不承诺任意JSON序列化器规范一致。

## 日期、修订与统计

人工开始、种植和观测日期使用DATE与上海自然日；软件事件使用UTC timestamp(6)，首次响应统一微秒精度。数值使用decimal(16,4)，最多12位整数与4位小数，超精度拒绝。观测 value 可以null，此时必须有缺测原因。有值时原因为空。已核实观测不可改状态或值，新版本supersedesId引用当前最高ACCEPTED版次。

当前数据以最高ACCEPTED revision为准，DRAFT／SUBMITTED不替代旧值。排除小区的记录仍存在，仅不参与当前有效数。按处理和指标计算N、missing、excluded、unrecorded、mean、minimum、maximum；mean四位小数HALF_UP，无N时均值极值null。不计算显著性。

正常结局FINISHED与中止ABORTED分开。关单生成dataHash，冻结包含每小区及指标的当前核实事实、排除状态、单位、方案和布局摘要、算法与结局。历史版次和事件仍在详情与导出保留。

## 运行与恢复

Compose提供数据库、后端、前端健康检查；数据库卷独立，端口可覆盖。Flyway执行版本化迁移，JPA只validate。升级前备份并在独立项目恢复，验证登录、业务响应、布局、修订与关单事实一致；不要在其他项目卷上执行测试。运行、授权及配置见README，非商业授权见LICENSE。

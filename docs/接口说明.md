# PlotTrial 接口说明

知华科技（上海如静知华信息科技有限公司） · <https://www.zhuatech.cn/> · 商业咨询微信 zhuatech / zhuatech2。

所有业务路由位于 /api。先GET /auth/csrf 获取会话令牌，POST /auth/login 提交username/password，再使用Cookie和返回的CSRF头执行写请求。GET /auth/me查看菜单和权限，POST /auth/logout退出；POST /auth/password验证oldPassword并设置newPassword后使会话失效。此文档不列固定测试口令。

| 路由 | 输入及职责 |
| --- | --- |
| GET /sites、/trials | search、status（试验）、page、size 1—100、sort newest／oldest；返回content与范围内total |
| GET /sites/{id}、/trials/{id} | record、events；试验另含treatments、measures、plots、observations、editors、algorithm、summary |
| POST／PUT /sites[/{id}] | requestKey、version、reference、name、departmentId、enabled |
| POST／PUT /trials[/{id}] | requestKey、version、reference、name、siteId、reviewerId、cropType、cropName、objective、blockCount、plotArea |
| POST／PUT /treatments[/{id}] | requestKey、version、trialId、code、name、description、control、enabled |
| POST／PUT /measures[/{id}] | requestKey、version、trialId、code、name、unit、minimum、maximum、required、enabled |
| POST／PUT /observations[/{id}] | requestKey、version、plotId、measureId、value或missingReason、note、observedDate、supersedesId |
| POST /{trials\|plots\|observations}/{id}/commands/{action} | requestKey、version、note；assign增加observerId；start／plant增加date |
| GET /trials/{id}/observations.csv | export权限，全部授权版次，文本公式转义，UTF-8 BOM |
| GET /{sites\|trials}/{id}/report.json | export权限，范围内完整证据，无广告字段 |
| GET /options、/dashboard、/audit | 安全目录、真实范围统计、授权审计 |
| GET／POST／PUT／DELETE /admin/{type}[/{id}] | 全范围admin管理；type白名单users／roles／departments／menus／permissions／dictionaries／settings |

创建version可以null；更新及命令必须为当前版本。requestKey为标准小写UUID；相同有效命令可重放原响应，变更输入必须新键。所有命令note非空；客户端日期YYYY-MM-DD，系统时刻不能由输入覆盖。数值可用十进制字符串防止浏览器浮点丢失。

试验动作：submit、withdraw、reject、approve、allocate、start、end、abort、reopen、close、cancel。小区动作：assign、receive、plant、request-exclusion、approve-exclusion、reject-exclusion。观测动作：submit、accept、reject、withdraw、cancel。状态、岗位与完成条件见操作手册。未列出的动作返回400 INVALID_ACTION。

400表示输入非法；401表示未登录／会话已失效；403表示权限或指定岗位不满足；409表示版本、状态、重复编号或关联冲突。响应只含错误code，不返回内部异常、密码或查询文本。常见代码STALE_VERSION、INVALID_STATE、OUT_OF_SCOPE、OPEN_OBSERVATION、CORRECTION_BASE_REQUIRED、PENDING_OBSERVATIONS、MISSING_REQUIRED_OBSERVATION。修改绑定身份、越权或跳过独立复核会被服务端拒绝。

业务导出保持原始授权内容，不插入公司联系方式。接口说明与源码为非商业学习版，商业集成须书面授权。
